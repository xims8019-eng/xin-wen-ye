# 新闻页（xin-wen-ye）— Vercel + Turso 版

个人资讯页：首页是每日速览——第一栏固定「江西专升本」，其后依次是「近期可申请」「国内外要闻」「本周学习」，首页底部有默认折叠的综合热榜；全部内容按五类整理（江西专升本 / 海外升学 / 海外实习、工作与签证 / 学习与实践 / 国内外观察与阅读），每条只归入一个主栏目。每天自动刷新一次，首页只放会改变决策的消息。

当前版本（2026-11-22 重构）和之前的主要差别：首页从三栏改成每日速览（江西专升本 + 近期可申请 + 国内外要闻 + 本周学习，每条带一句“和我有什么关系”，点开在页内展开）；五类栏目各有阶段划分（升学分在读可准备 / 专科毕业可申请 / 本科毕业可申请；工作分在读实习 / 专科毕业后从中国直接求职 / 海外留学期间及毕业后就业，岗位卡写明地点、能否境内远程、学历经验要求、是否接受境外申请与签证支持，政策单独标记）；海外栏「签证新政 · 固定区」现有 4 条（耶鲁 D/S、新西兰短期工签、新加坡 MOM、日本入管厅），明确不适用的条目（仅限本科、韩国试点等）已移出首页，同一事件合并去重；学习栏全量只留现在能报名、能看回放或能直接开始学的内容；综合热榜恢复在首页底部、默认折叠（娱乐分类仍未恢复）；全站入库前解析中转链接（Google 新闻 / Bing / MSN）到发布方直达地址，解析不到的只留摘要；Google 新闻占位摘要入库时丢弃；学习栏「可报名」列表只收录已确认官方入口的条目。同日 b 版补丁：首页顺序按简报改正（国内外要闻和本周学习紧跟近期可申请，两个海外栏移到其后）；学习栏「已结束」判定补上裸词收官/落幕/闭幕与赛报/获奖/一等奖（带回放/回看的除外）。同日 c 版补丁：首页选稿再收紧——海外栏只讲单一外国国籍申请人（如印度申请人、新西兰签证 64.1% 统计、印度博士生、越南留学生申加拿大）的移出首页；江西栏已结束的考区提醒（如 2026 年九江考区温馨提醒）移出可见列表；国内外要闻过滤与江西及留学目的地无关的地方节庆交通提示（如大理州庆交通提示）。同日 d 版补丁：新西兰短期毕业工签（Short-term Graduate Work Visa，2026-11-23 起、NZQCF 5–7 级）以「未来路径」加回固定区（江西大专本身不算，与要求学士学位的 PSWV 扩大是两条不同的签证）；学习栏新增「只限特定企业/机构员工或其子女」过滤（如 WCMA 乳制品企业员工子女奖学金）；D/S 同事件去重补修——Inside Higher Ed 2026-09-13 的旧解释文并入耶鲁条目、请愿/抗议类条目永不进固定区，固定区恢复为正好 4 条。

## 目录

- `client/` — React 前端（`src/App.tsx` 是全部界面，`src/api.ts` 是类型化接口客户端，POST `/api/action`）
- `api/action.ts` — Vercel Serverless Function：`{action, args}` 路由到 `server/src/actions.ts`
- `api/cron.ts` — Vercel Serverless Function：定时刷新入口，调 `refreshAll`
- `server/src/actions.ts` — 全部服务端逻辑：抓取、解析、链接解析、去重、缓存、五类首页、学习栏目、签证固定区、收藏与订阅（18 个接口）
- `server/src/ctx.ts` — 数据库连接（Turso / 本地 SQLite）与首次建表
- `server/src/llm.ts` — 可选的大模型客户端（OpenAI 兼容接口）
- `server/src/schema.ts` — 数据库三张表定义
- `drizzle/` — 建表 SQL（与 `ctx.ts` 里内联的建表语句一致）
- `config/feeds.json` — 分类新闻（9 个）、订阅目录（9 个）清单
- `config/learning.json` — 学习栏目数据源与规则
- `config/columns.json` — 首页五类与每日速览的搜索词、签证固定区 4 条、屏蔽域名与固定区禁用来源
- `docs/cron.md` — 定时更新配置
- `docs/summary-logic.md` — 摘要生成逻辑说明
- `docs/link-resolution.md` — 链接解析、去重与屏蔽规则说明
- `.env.example` — 需要的环境变量名（只列名称，无值）
- `DATA-PLAN.md` — 建站与历次改版的数据源实测记录（哪些源验过、哪些被弃用及原因）

## 本地运行

```bash
bun install
bun run build        # 打包前端到 client/dist
bun run typecheck    # client + server 两个 tsconfig
```

不配任何环境变量也能跑：数据库默认用本地文件 `./data/app.db`（首次使用时自动建表），大模型未配置时降级运行（见下）。

## 部署到 Vercel（免费版）+ Turso（免费版）

1. **Turso 建库**（免费版 1 个库、9 GB 存储够用）：
   ```bash
   turso db create xin-wen-ye
   turso db show xin-wen-ye --url        # 得到 libsql://...turso.io
   turso db tokens create xin-wen-ye     # 得到 auth token
   ```
   也可以在 [Turso 控制台](https://turso.tech) 建库并复制连接地址和 token。
2. **Vercel 导入**：在 [Vercel 控制台](https://vercel.com) 用「Add New → Project」导入这个 GitHub 仓库。Vercel 会按 `vercel.json` 构建（`bun run build`，产物目录 `client/dist`），不需要改构建设置。
3. **填环境变量**（Vercel 项目 → Settings → Environment Variables）：
   | 变量 | 必填 | 说明 |
   |---|---|---|
   | `TURSO_DATABASE_URL` | 是 | Turso 连接地址（`libsql://...`） |
   | `TURSO_AUTH_TOKEN` | 是 | Turso auth token |
   | `OPENAI_API_KEY` | 否 | 不填也能跑，见「不配大模型 key」 |
   | `LLM_BASE_URL` | 否 | 兼容接口地址，默认 `https://api.openai.com/v1` |
   | `LLM_MODEL` | 否 | 模型名，默认 `gpt-4o-mini` |
   | `CRON_SECRET` | 否 | 建议填，保护 `/api/cron` 不被随意触发 |
4. 部署完成后打开 Vercel 给的域名即可使用；首次打开会自动建表并拉取新闻。

## 定时刷新

`vercel.json` 里配了一条定时任务：每天 UTC 00:02（北京时间 08:02）调 `/api/cron`，触发全量刷新。注意 Vercel 免费版的限制：

- 每天最多一次定时触发，且触发时间会在整点内浮动（不保证 exactly 00:02）。
- Serverless Function 的 `maxDuration` 在免费版（Hobby）上限是 60 秒，本仓库已按 60 秒配置（`api/action.ts`、`api/cron.ts`、`vercel.json` 三处一致），免费版可以正常部署。注意：60 秒是硬上限。**不配大模型 key 时**全量刷新只是拉取公开 RSS 和做规则筛选，之前实测 53 秒跑完；**配了 key 时**中文整理要调多次模型，全量刷新（9 个分类 + 五类首页 + 学习栏 + 热榜 + 订阅源）通常超过 60 秒，定时任务可能在刷新完成前被掐断——已写完的栏目缓存会保留，页面仍可读旧缓存，下次打开或手动刷新会继续补全。如需完整跑完一次带模型整理的全量刷新，需要 Vercel Pro（上限 300 秒）或把刷新拆成多次调用。

## 不配大模型 key 也能跑

抓取部分全部是公开接口，不需要任何密钥。只有 4 处用到大模型（新闻详情要点、学习 / 江西 / 海外三栏的中文整理），每处都有降级处理：未配置 `OPENAI_API_KEY` 时直接走降级分支，展示来源自己的摘要原文，页面其余功能不受影响。只配了 `ANTHROPIC_API_KEY`、没有 OpenAI 兼容 key 时同样降级（本项目没有 Anthropic 客户端）。

## 没包含的东西

- `node_modules/`、构建产物（`client/dist/`、`server/dist/` 等）、`data/app.db` 数据库文件 — 都是可再生成的，且数据库里是缓存和个人订阅/收藏，不属于源码。
- 任何密钥 — 包里只有 `.env.example` 的变量名。

同日 e 版补丁：学习栏「只限特定企业/机构员工或其子女」过滤补上英文单数形式——WCMA 奖学金存量文本写作 "Any employee or child of an employee …"，单数的 "child of an employee" 不命中 d 版的复数信号，自建版（无模型）因此漏过；e 版在同一分支新增 `/child(ren)? of (an?|the)? (employee|staff)/i` 与 `/employee(s)? or (a )?child of/i`，并用存量原文验过。

同日 f 版补丁：学习栏三条残留过滤——（1）活动类标题（公开课/大咖课/讲座/论坛等）且正文写明「X月X日……举行/举办/召开」日期不晚于今天、无将来标记、无回放无报名时判为已办完的活动报道（东湖大咖公开课）；（2）正文出现专硕/学硕即按硕士学段处理（专硕住宿政策新闻）；（3）只限单一地方学区学生或仅限高中及以下学生的奖学金移出（St. Joseph 学区奖学金）。三条都是 isLearningNotActionable 的确定性分支，入库和每次读回都执行。

同日 g 版补丁：学习栏两处补修——（1）已举办活动报道的日期窗口由 30 字放宽到 60 字：东湖大咖公开课的真实存量摘要「11月21日，由武汉市经济和信息化局主办、华中科技大学承办的"江城群星"年度大咖课举行」在「日」与「举行」之间隔了 35 字，f 版的 30 字窗口不命中、自建版漏过；g 版放宽到 60 字（仍限同一句），用真实文本重测确认旧窗口不命中、新窗口命中，防误伤用例仍保留。（2）高中生信号补两个英文写法：People《Deaf Student-Athlete Earns 10 College Scholarship Offers Following Successful High School Career》是美国高中橄榄球运动员的奖学金故事，文本只有 High School Football Career，f 版信号一个都没命中；g 版新增 high school football / high school athlete(s)，并用实存文本验过。连带效果：WTHR 的 INvestEd 奖学金（含 college juniors and seniors）命中既有信号一并移出——只限印第安纳州居民，移出正确。

同日 h 版补丁：三处条目修正——（1）新西兰短期毕业工签的状态标签不再写死，改为按生效日 2026-11-23 与新西兰当地日期（Pacific/Auckland）在读回时实时计算：生效日前显示「即将生效」，生效日当天起显示「已生效」（之前写死为已生效，页面日期还是 11 月 22 日时与卡片自写的「11 月 23 日起」矛盾）；「11月23日起」文案与「未来路径」说明未动。（2）政策类卡片不再带申请字段：服务端对 kind=policy 一律不输出申请截止日期，相关性文案只写政策影响哪类学生，前端对政策卡隐藏资格徽标、申请截止行和升学字段，展开文案改为「展开详情」——只有确实开放申请的项目/岗位才显示这些字段（起因：耶鲁 OISS 的 D/S 说明卡因底层 eligibility=diploma_eligible 同时显示了「专科可申请」和「看条件和截止日期」）。（3）NIC Winter Internship 确定性改判栏目：之前被整理进「海外升学」，h 版按标题/链接改判为「海外实习、工作与签证」（在读实习），地点为印度新德里 NIC 总部线下、不能从中国境内远程参加，是否接受中国境内学生申请官方未说明、资格保留「未说明」，且明确排除在「近期可申请」之外。
同日 i 版补丁：NDTV 的 MeitY 实习与 India.com 的 NIC Winter Internship 按项目合并——用户读 NDTV 原文核实两者是同一个项目（NDTV 原文开头即为 NIC Winter Internship 2026 公告，事实完全一致），而 h 版匹配器只认标题/链接里的 NIC 字样、NDTV 标题不含 NIC 而漏检；i 版新增项目级匹配器（标题+整理文本+要点），入库和每次读回都把本项目全部转述收敛为一条、以 NDTV 为代表，归入「海外实习、工作与签证」（在读实习），留下的条目写入完整核实事实（新德里 NIC 总部线下、官方入口 dii.nic.in、资格「未说明」、截止日期官方未确认故为空），且明确排除在「近期可申请」之外；海外缓存键升到 v18。
